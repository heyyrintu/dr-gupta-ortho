# Dr. Siddharth Gupta — Orthopaedic & Robotic Joint Surgeon

Website for drsiddharthguptaortho.in — Vite + React + TypeScript + three.js.

```bash
npm install
npm run dev       # local dev server
npm run build     # production build in dist/
```

- **Working with Claude Code?** Start with `CLAUDE.md`, then `docs/BUILD_SPEC.md`.
- **Content still needed from the clinic:** `docs/CONTENT_TODO.md` (OPD timings, reviews, rating…).
- All copy and practice data: `src/content/site.ts`.

### Opening in Claude Code
```bash
cd dr-siddharth-gupta-ortho
claude
> Read CLAUDE.md and docs/BUILD_SPEC.md, run the dev server, then …
```
